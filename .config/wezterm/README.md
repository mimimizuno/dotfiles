# WezTerm

設定本体は[`wezterm.lua`](wezterm.lua)です。`~/.config/wezterm`にリンクされ、変更は自動で再読み込みされます。

## 表示

- フォントサイズ15、IME有効
- 背景の不透明度0.85、macOS背景ぼかし20
- 1タブだけのときはタブバーを隠す
- アクティブタブを黄系、非アクティブタブを青灰色で表示
- カラースキームはAdventureTime

## Leaderキー

Leaderは`Ctrl+a`です。1秒以内に次のキーを押すと操作になります。

| 操作 | 動作 |
| --- | --- |
| `Ctrl+a`, `s` | 左右にペイン分割 |
| `Ctrl+a`, `v` | 上下にペイン分割 |
| `Ctrl+a`, `h/j/k/l` | 左/下/上/右のペインへ移動 |
| `Ctrl+a`, `c` | 新しいタブ |
| `Ctrl+a`, `[` | Copy Mode |
| `Ctrl+a`, `x` | 現在のペインを閉じる（確認あり） |
